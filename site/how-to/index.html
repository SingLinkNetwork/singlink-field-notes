這個站怎麼上線

免費位址是 GitHub Pages：singlinknetwork.github.io/singlink-field-notes。自訂 notes.singlinkvpn.com 需要你在 Cloudflare 加 CNAME，我這邊沒有你們的 DNS 權限。

  1. 改句子後跑 sh iterate.sh，再 git push，Actions 會自動發佈。
  2. Search Console 提交 sitemap：https://singlinknetwork.github.io/singlink-field-notes/sitemap.xml
  3. 不要把同一篇再複製到 Google Sites／Blogger 農場。
  4. 大陸站不做 VPN 宣傳矩陣。

為什麼是一個自有站，不是 1000 個免費帳號

規模化門頁會被當垃圾內容。一個網域、1000 篇不重複現場、內鏈清楚，比八十個分身便宜，也比較能留。

自我迭代

每次改句子庫或市場表，跑 python3 generate.py && python3 verify.py。驗證不過就不要上線。
